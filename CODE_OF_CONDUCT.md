# Code of conduct

This applies to the ChorusDraft GitHub repo: issues, pull requests,
discussions, comments, and other project spaces on GitHub.

Stay on the software. Disagreement is fine. Insults, harassment, and pile-ons
are not.

Do not:

- Harass, threaten, or dox anyone
- Use slurs or post hate
- Share other people's private posts, credentials, tokens, or personal
  information
- Put secrets, private posts, or exploit details in a public issue
  (see [SECURITY.md](SECURITY.md))
- Spam, advertise, or derail threads

Report a problem with this repo through GitHub private vulnerability reporting
if it is a security issue. For other conduct problems, contact the maintainer
through GitHub. Do not file a public issue if that would spread the harm.

The maintainer can edit or hide comments, close or lock threads, and block
people. Repeated or serious violations get you removed from these spaces.

This is about project conduct. It does not replace the license.
