# Elixir experimental changelog

This branch tracks the separate `elixir-experimental` work. Its implementation
history is recorded in [`elixir/CHANGELOG.md`](elixir/CHANGELOG.md).

The supported Ruby history is maintained on `main-ruby`. Future Ruby 0.51.2 work
is isolated on `ruby-testing` and is not part of this experiment.

No Elixir release has been published. The current files are an unfinished
checkpoint, not release notes for the supported Ruby 0.51.1 packages.
